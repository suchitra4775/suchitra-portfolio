# Suchitra Dhakane — Angular Portfolio

A responsive personal portfolio built with Angular 18.

## Stack
- Angular and TypeScript
- HTML and CSS
- Responsive layouts

## Run locally
1. Install Node.js (LTS).
2. Open a terminal in this project folder.
3. Run `npm install`.
4. Run `npm start` and open the local URL printed in the terminal.
5. Run `npm run build` to create a production build.

## Before publishing
- Replace contact placeholders with links you want to share publicly.
- Confirm all education dates and project descriptions are accurate.
- Add verified GitHub/live-demo URLs for completed projects.
- Do not place identity documents, certificates, home address, birth date, passwords, or private files in `public/`.

## Deploy
Use a static hosting provider such as Netlify or Vercel. For this Angular project, check the actual build output under `dist/myapp/browser` (if the build configuration creates a browser subfolder) before choosing the publish directory.
